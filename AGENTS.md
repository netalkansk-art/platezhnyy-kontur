# Работа с репозиторием

- После каждого завершённого и проверенного шага сохраняй версию отдельным коммитом с понятным описанием на русском и отправляй её в репозиторий проекта на GitHub.
- Перед коммитом проверь список и содержимое включённых файлов. Пароли, ключи, токены, клиентские данные, локальные базы, выгрузки и папку .venv храни локально.
- Для первого коммита и первой отправки дождись явного «да» пользователя. Соблюдай последующие указания пользователя о приостановке отправки.
