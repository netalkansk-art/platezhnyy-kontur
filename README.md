# Платёжный контур

Локальный прототип на FastAPI и SQLite. Интерфейс находится в index.html, сервер раздаёт его по HTTP. Работайте через адрес сервера.

## Запуск на Windows

В PowerShell из папки проекта выполните команды. Нужен Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8766
```

Откройте http://127.0.0.1:8766. Выберите демо-пользователя и войдите с паролем, который показан на экране входа, или демонстрационным кодом.

При первом запуске создаётся `payments.sqlite3` с пятью примерами. Повторный запуск использует тот же файл. Для другой базы задайте переменную окружения `PAYMENTS_DB` с абсолютным путём. SQLite хранит заявки, историю, решения согласующих и оплаты. Реестр выгружается в XLSX с учётом активных фильтров.

## Перенос прежних локальных заявок

Если заявки создавались в файле index.html, откройте файл напрямую в том же браузере и профиле, где работали раньше. Кнопка «Сохранить прежние заявки для переноса» появляется при наличии старых данных. Скачайте JSON и выполните команду до первого изменения в целевой базе.

```powershell
.\.venv\Scripts\python.exe server.py --import-legacy 'C:\путь\legacy-payments.json'
```

Импорт сохраняет номера, статусы и историю. Исходное хранилище браузера сохраняется. Если прототип открывался по другому адресу, его старые данные находятся в хранилище того адреса. Для переноса нужен JSON со значением ключа `payment-approval-demo-v1` из того браузера и адреса.

## Доступ

Этот запуск доступен на компьютере, где работает сервер. При размещении на общем сервере браузеры должны открывать один адрес и работать с одной базой. Пароль, SMS и роли пока демонстрационные, права проверяются в интерфейсе. Перед доступом по сети необходима серверная аутентификация и проверка прав.

## Публичное демо

GitHub Pages публикует интерфейс, браузерный адаптер и стартовые вымышленные заявки. Демо сохраняет изменения только в браузере посетителя. Сервер FastAPI и локальная база SQLite в сборку Pages не входят.
